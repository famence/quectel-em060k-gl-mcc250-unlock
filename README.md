# Quectel EM060K-GL (`MCC 250` / Russia LTE) Software Unlock for GL.iNet Mudi V2

Программная разблокировка сотового модема **Quectel EM060K-GL** (`EM060KGLAAR01A11M2G_01.202.01.202`) для работы в российских LTE-сетях (`MCC 250`) без разборки устройства, программаторов и модификации разделов загрузчика/IMEI/калибровок.

Репозиторий содержит:
- **Готовый автоматический скрипт разблокировки и настройки по SSH** для роутера **GL.iNet Mudi V2 (`GL-E750V2`)** — [`unlock_mudi_em060k.sh`](./unlock_mudi_em060k.sh) (и скрипт мгновенного отката [`rollback_mudi_em060k.sh`](./rollback_mudi_em060k.sh)).
- **Автономный статический USB ADB-клиент** [`src/mudi_adb.go`](./src/mudi_adb.go) (`bin/mudi_adb_mips_softfloat` под `mips_24kc`), работающий напрямую поверх Linux `usbfs` внутри роутера и включающий генератор ключей `AT+QADBKEY`.
- **Полный инструментарий реверс-инжиниринга и пересборки образов** в [`tools/`](./tools/): распаковщик `q6zip` v3.2 (`SDX12`), верификатор однобитного патча на всех 4096 значениях MCC и генератор цепочки сертификатов X.509 DER / подписи QPSA RSA-2048 (`modem.b01`, `modem.mdt`).

## 1. Симптомы проблемы

На модеме **Quectel EM060K-GL** с прошивкой `EM060KGLAAR01A11M2G_01.202.01.202` (в соответствии с бюллетенем Quectel PCN 2022113001) встроена программная блокировка регистрации в сетях с кодом страны **Россия (`MCC 250`)** и **Иран (`MCC 432`)**:

- SIM-карта читается штатно (`AT+CPIN?` → `+CPIN: READY`).
- Сканирование эфира `AT+COPS=?` видит все российские базовые станции LTE (`25001` МТС, `25002` МегаФон, `25011` Yota, `25020` Tele2/T-Mobile, `25099` Билайн).
- При попытке регистрации модем бесконечно остаётся в поиске или ограниченном обслуживании (`+CEREG: 0,2` / `+CEREG: 0,0`, `AT+QENG="servingcell"` → `"SEARCH"` или `"LIMSRV"`).
- Дополнительно на роутерах **GL.iNet Mudi V2 (`GL-E750V2`)** при отсутствии LTE-регистрации веб-интерфейс может переключить интерфейс `modem_1_1_2` на устаревший протокол `proto '3g'` (`/dev/ttyUSB3`), из-за чего фоновый `pppd` каждую минуту сбрасывает радиомодуль командами `ATD*99***1#`.

## 2. Быстрый старт (GL.iNet Mudi V2 / OpenWrt)

### Требования
- Роутер **GL.iNet Mudi V2 (`GL-E750V2`)**, доступный по SSH (по умолчанию `root@192.168.8.1`).
- Модем **Quectel EM060K-GL** с версией прошивки `EM060KGLAAR01A11M2G_01.202.01.202` и отключённым аппаратным OEM Secure Boot (`AT+QSECBOOT="status"` → `0`).

### Запуск в одну команду (с вашего Mac или Linux ПК)

```bash
git clone https://github.com/famence/quectel-em060k-gl-mcc250-unlock.git
cd quectel-em060k-gl-mcc250-unlock
chmod +x unlock_mudi_em060k.sh rollback_mudi_em060k.sh

# Формат: ./unlock_mudi_em060k.sh [root@IP_роутера] [APN_оператора]
./unlock_mudi_em060k.sh root@192.168.8.1 internet.yota
```

Часто используемые APN российских операторов:
- **Yota**: `internet.yota`
- **МегаФон**: `internet`
- **МТС**: `internet.mts.ru`
- **Билайн**: `internet.beeline.ru`
- **T2 (Tele2) / Т-Мобайл**: `internet.tele2.ru` / `tt`

### Что делает скрипт `unlock_mudi_em060k.sh` автоматически:
1. Проверяет точную версию прошивки (`EM060KGLAAR01A11M2G_01.202.01.202`) и статус `AT+QSECBOOT="status"` (`0`).
2. Запрашивает у модема `AT+QADBKEY?`, вычисляет ответный ключ по алгоритму MD5-crypt (`$1$<challenge>$` от секрета `SH_adb_quectel`), разблокирует ADB и временно включает USB-интерфейс ADB (`AT+QCFG="usbcfg",0x2C7C,0x030B,1,1,1,1,1,1,0`).
3. Выполняет золотой бэкап NV-параметров (`AT+QPRTPARA=1`) и сохраняет полные копии заводских файлов `modem.b19`, `modem.b01`, `modem.b00`, `modem.mdt` как внутри энергонезависимой памяти модема (`/usrdata/cache/orig_fw_headers/`), так и на ваш компьютер в папку `backups/`.
4. Изменяет **1 байт на месте** в `/firmware/image/modem.b19` (смещение `0x15b595`: `0x40` → `0x50`), атомарно обновляет `/firmware/image/modem.b01` и `/firmware/image/modem.mdt`, сверяет `sha256sum` всех трёх файлов и переводит корневую ФС обратно в `read-only`.
5. Перезапускает модем, проверяет через сторожевой таймер статус радиопроцессора Hexagon (`subsys1/state == ONLINE`, `crash_count == 0`), при любой ошибке автоматически возвращает заводские файлы.
6. Отключает ADB (`AT+QCFG="usbcfg",0x2C7C,0x030B,1,1,1,1,1,0,0`), настраивает в OpenWrt штатный протокол `proto 'qcm'` (`/dev/cdc-wdm0`) с указанным APN и проверяет регистрацию в сети LTE (`+CEREG: 0,1`).

### Откат к заводскому состоянию
В любой момент можно вернуть 100% заводские файлы `modem.b19`, `modem.b01` и `modem.mdt`:
```bash
./rollback_mudi_em060k.sh root@192.168.8.1
```

## 3. Технический разбор (Reverse Engineering)

### 3.1. Архитектура прошивки модема
Внутри Quectel EM060K-GL (`Qualcomm Snapdragon X12 / SDX12`, платформа `sdxnightjar`) работают два процессора:
- **Прикладной процессор (ARM Cortex-A7)** под управлением Linux `5.4.161-perf`, где корневая файловая система (`ubi0:rootfs`, раздел `system`) смонтирована в режиме чтения (`ro`), а пользовательский раздел `usrfs` (`/dev/ubi1_0`) смонтирован в `/usrdata` (`rw`).
- **Радиопроцессор (Qualcomm Hexagon DSP)**, прошивка которого загружается PIL-загрузчиком из файлов `/firmware/image/modem.mdt` и `/firmware/image/modem.b00`..`modem.b29`.

Динамически подгружаемый RO/Code-сегмент радиопрошивки `modem.b19` (`8 593 408` байт) сжат проприетарным страничным алгоритмом **Qualcomm `q6zip` версии `v3.2`** (`3516` страниц по `4096` байт = `14 401 536` байт распакованного кода Hexagon).

### 3.2. Функция проверки запрещённых PLMN (`reg_sim.c`)

### 3.3. Однобитный патч в сжатом потоке `q6zip`
Трассировка декодера `q6zip` на странице `541` ([`tools/verify_patch_page541.py`](./tools/verify_patch_page541.py)) показала, что инструкция `0xd021d654` (`0x1048400c`) хранится в `modem.b19` в открытом виде как 32-битный литерал `LITERAL[110]` по файловому смещению **`0x15b594`** (`1422740` байт):

- **Было (`0x15b594`)**: `0c 40 48 10` (`0x1048400c`) → `p0 = cmp.eq(r16, #0); if (!p0.new) jump:nt 0xd021d66c`
- **Стало (`0x15b594`)**: `0c 50 48 10` (`0x1048500c`) → `p0 = cmp.eq(r16, #16); if (!p0.new) jump:nt 0xd021d66c`

Поскольку `r16 = extractu(r0, #4, #8)` — беззнаковое 4-битное число (`0 <= r16 <= 15`), условие `r16 == 16` всегда ложно для любого входа `0x000..0xfff`. Это полностью выключает блокировку `MCC 250`, не переназначая её ни на какой другой MCC. Во второй ветке (`0xd021d674`, Иран `432`) декодер `q6zip` применяет команду `PATCH16_0_NEW(r25=-8, val16=0xc20a)`, которая затирает младшие 16 бит (`15:0`) слова `out[405]`, поэтому инструкция `0xd021d674` остаётся неизменной (`0x1048c20a`).

### 3.4. Переподпись `modem.b01` и `modem.mdt`
В `modem.b01` хранятся таблица SHA-256 хешей всех 31 сегмента ELF, 256-байтная подпись QPSA RSA-2048 (`SW_ID = 0x0000000000000002`, `HW_ID = 0x001890E100000000`) и цепочка из трёх DER-сертификатов X.509 (`Cert 0..2`), где атрибуты `SW_ID`, `HW_ID`, `OEM_ID`, `SW_SIZE`, `MODEL_ID` закодированы типом ASN.1 `T61STRING` (`0x14`). Скрипт [`tools/build_patched_modem.py`](./tools/build_patched_modem.py) обновляет хеш сегмента `#19` (`modem.b19`) и переподписывает контейнер с побайтовым сохранением DER-шаблонов `TBSCertificate`.
